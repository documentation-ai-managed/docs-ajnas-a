## Set Up Your First Marketing Campaign

Launch a PPC campaign as your first step. Use the dashboard to configure.

<Steps>
  <Step title="Select Campaign Type" icon="plus">
    Choose **PPC** from the dashboard.
  </Step>
  <Step title="Configure Settings" icon="settings">
    Define budget, targeting, and keywords. Here's a sample API call to create it programmatically:
    
    <CodeGroup tabs="cURL,JavaScript">
      ```bash
      curl -X POST https://api.example.com/v1/campaigns \
        -H "Authorization: Bearer YOUR_API_KEY" \
        -H "Content-Type: application/json" \
        -d '{
          "name": "First PPC Campaign",
          "budget": 500,
          "keywords": ["digital marketing dubai", "seo uae"]
        }'
      ```
      ```javascript
      const response = await fetch('https://api.example.com/v1/campaigns', {
        method: 'POST',
        headers: {
          'Authorization': 'Bearer YOUR_API_KEY',
          'Content-Type': 'application/json'
        },
        body: JSON.stringify({
          name: 'First PPC Campaign',
          budget: 500,
          keywords: ['digital marketing dubai', 'seo uae']
        })
      });
      ```
    </CodeGroup>
  </Step>
  <Step title="Launch and Monitor" icon="play">
    Review preview, then hit **Launch**. Track ROI in real-time.
  </Step>
</Steps>
