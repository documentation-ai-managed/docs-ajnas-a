## Google Analytics and Ads

Connect Ajnas A to Google Analytics and Google Ads to monitor traffic sources and ad performance. This setup provides detailed reports on your SEO and PPC efforts.

<Steps>
  <Step title="Enable API Access" icon="settings">
    In your Ajnas A dashboard, navigate to Integrations > Google. Generate an OAuth client ID from the Google Cloud Console.
  </Step>
  <Step title="Authorize Connection">
    Paste your client ID and secret into Ajnas A. Complete the OAuth flow to grant access to Analytics and Ads data.
  </Step>
  <Step title="Verify Data Flow">
    Run a test sync. Check the Ajnas A reports for imported metrics like sessions and conversions.
  </Step>
</Steps>

```javascript
// Example: Fetch Google Analytics data via Ajnas A API
const response = await fetch('https://api.example.com/v1/integrations/google-analytics', {
  headers: {
    'Authorization': 'Bearer YOUR_API_KEY',
    'Content-Type': 'application/json'
  }
});
const data = await response.json();
console.log(data.sessions);
```

### Webhook Configuration

Create a webhook endpoint to receive real-time campaign events.

<CodeGroup tabs="Node.js,Python">
````javascript
// Node.js webhook handler
const express = require('express');
const app = express();
app.use(express.json());

app.post('/webhook/ajnas-a', (req, res) => {
  console.log('Lead data:', req.body.lead);
  res.status(200).send('OK');
});

app.listen(3000);
````
````python
# Python webhook with Flask
from flask import Flask, request

app = Flask(__name__)

@app.route('/webhook/ajnas-a', methods=['POST'])
def webhook():
    data = request.json
    print('Lead data:', data['lead'])
    return 'OK', 200
````
</CodeGroup>

Configure the webhook URL in Ajnas A dashboard: `https://your-webhook-url.com/webhook/ajnas-a`.
